# Unbiased by Nature

Work in progress. Private.

Detecting local pockets of algorithmic bias with the Dendritic Cell Algorithm, an
Artificial Immune System anomaly detector.

The question I'm testing: do standard fairness tools, which are mostly global averages
or axis-aligned subgroup audits, miss oddly-shaped local pockets of unfairness that a
per-instance, subgroup-agnostic anomaly detector can catch? Or is the immune framing
just relabeling "bias" as "danger"? The repo is built to answer that honestly, with
ground-truth injected bias and real baselines.

Private until there's a preprint. Findings and the full writeup land here once the
experiments are run.
